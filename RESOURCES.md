# Resources

Primary sources for SLFRF. Each link below resolved when checked on October 20, 2026. Treasury updates some
documents in place, so a link can stay the same while its contents change: check the version date inside.

## Current sources

- [Treasury: State and Local Fiscal Recovery Funds](https://home.treasury.gov/policy-issues/coronavirus/assistance-for-state-local-and-tribal-governments/state-and-local-fiscal-recovery-funds): rules, guidance, FAQs and reporting materials.
- [Treasury: Recipient compliance and reporting responsibilities](https://home.treasury.gov/policy-issues/coronavirus/assistance-for-state-local-and-tribal-governments/state-and-local-fiscal-recovery-funds/recipient-compliance-and-reporting-responsibilities)
- [31 CFR Part 35 (eCFR)](https://www.ecfr.gov/current/title-31/subtitle-A/part-35): the SLFRF regulation as currently in force.
- [2 CFR Part 200 (eCFR)](https://www.ecfr.gov/current/title-2/subtitle-A/chapter-II/part-200): the Uniform Guidance.
- [HUD Qualified Census Tract locator](https://www.huduser.gov/portal/sadda/sadda_qct.html)
- SAM.gov Assistance Listing 21.027, Coronavirus State and Local Fiscal Recovery Funds (search sam.gov for 21.027).

## The 2021 sources the guide was built on

These are the links in the original guide. They are history, not current guidance.

- [Section 603, Social Security Act](https://www.govinfo.gov/content/pkg/COMPS-15671/pdf/COMPS-15671.pdf)
- [Interim Final Rule, 86 FR 26786 (May 17, 2021)](https://www.govinfo.gov/content/pkg/FR-2021-05-17/pdf/2021-10283.pdf)
- [SLFRF Compliance and Reporting Guidance](https://home.treasury.gov/system/files/136/SLFRF-Compliance-and-Reporting-Guidance.pdf) (the guide used the June 24, 2021 version; Treasury has revised it since)
- [Frequently Asked Questions](https://home.treasury.gov/system/files/136/SLFRPFAQ.pdf) (the guide used the July 19, 2021 version)
- 2019 Census poverty thresholds: the file the guide linked now returns 404.
